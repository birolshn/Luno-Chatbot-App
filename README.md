# 🤖 Luno Chatbot App

Luno is a modern AI-powered chatbot mobile application built with **Flutter** and powered by a **LLaMA-based API**. The app provides fast, conversational AI responses through a clean and user-friendly interface.

## 🚀 Features

- AI-powered chat using LLaMA API
- Real-time message streaming
- Clean and responsive Flutter UI
- Cross-platform support (Android & iOS)
- Chat history support
- Error handling and loading states

## 🛠 Tech Stack

- **Framework:** Flutter (Dart)
- **AI Model:** LLaMA (via API)
- **HTTP Client:** Dio / http
